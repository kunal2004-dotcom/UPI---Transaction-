# UPI Transaction Analysis Dashboard 📊

Welcome to the **UPI Transaction Analysis Dashboard** project! This repository contains an analytical solution for exploring trends, patterns, and customer behaviors in UPI (Unified Payments Interface) transactions using a simulated Excel dataset.

---

## 📂 Project Overview

The project focuses on analyzing UPI transaction data to provide actionable insights through data visualization and statistical analysis. Using Python for data preparation and Power BI for visualization, this project demonstrates how fintech organizations can leverage transaction data to better understand customer preferences, transaction behaviors, and payment trends.

---

## ✅ Features

- ✅ **Transaction Trend Analysis:** Visualize transaction volume over time.
- ✅ **Customer Insights:** Explore customer demographics like age, gender, and location.
- ✅ **Payment Method Insights:** Compare usage patterns across different devices and payment methods.
- ✅ **Merchant Analysis:** Identify popular merchants and transaction purposes.
- ✅ **Transaction Status:** Analyze success and failure rates in transactions.
- ✅ **Bank Comparisons:** Examine transaction behaviors across different banks.

---

## 📊 Dataset

The project uses a **simulated but realistic Excel dataset**, which includes the following attributes:

| Column Name                | Description                             |
|----------------------------|-----------------------------------------|
| TransactionID               | Unique ID for each transaction          |
| TransactionDate             | Date of transaction                     |
| Amount                     | Transaction amount                      |
| BankNameSent               | Sending bank name                       |
| BankNameReceived           | Receiving bank name                     |
| RemainingBalance           | Account balance after the transaction   |
| City                       | Transaction location                    |
| Gender                     | Customer gender                         |
| TransactionType            | Type of transaction (Transfer/Payment)   |
| Status                     | Transaction outcome (Success/Failed)     |
| TransactionTime            | Time of transaction                    |
| DeviceType                 | Device used (Mobile/Laptop/Tablet)      |
| PaymentMethod              | Method used for payment (QR, UPI ID, etc.) |
| MerchantName               | Receiving merchant name                 |
| Purpose                    | Transaction purpose (Food, Travel, etc.) |
| CustomerAge                | Age of the customer                     |
| PaymentMode                | Instant or Scheduled payments           |
| Currency                   | Currency of the transaction            |
| CustomerAccountNumber      | Account number of the customer          |
| MerchantAccountNumber      | Account number of the merchant          |
